Claude Command Center

A visual system for a cockpit that runs a fleet of agents. Dark-first, terminal-adjacent, and engineered so the answer to "who needs me?" is a one-second glance. Tokens, component redlines, states, motion, and accessibility criteria — drop-in ready for React 19 + plain CSS.

Engineered Ledger · warm graphite accent-bar status language WCAG AA · CVD-safe for MipYip, LLC
01

The cockpit

The target four-region layout, assembled and populated at real density. Beacon bar spans everything and never scrolls; category rail switches rooms without touching it; the task tree carries typed edges, a blocked banner and collapsed roll-ups; the terminal hosts tabs and a theme swatch. Selection (neutral fill) and status (colored left bar) are separate channels, so a row can show both at once.

03

Status — the primary channel

Color carries status, but never alone — each state owns a distinct shape, and the two that share a silhouette are split by motion (working pulses; idle is still and recedes). That's what keeps the fleet readable for the ~8% with color-vision deficiency. Waiting is the one state allowed to pull the eye.

working#34d399
Actively producing output — the alive state. Filled circle, softly pulsing. Calm, not distracting, even across 20 rows.
10.1:1 on term · 9.9:1 on bg · AAA
waiting · input#60a5fa
Waiting on the human — the attention state. Filled square + left accent bar. The only state that earns visual weight. Highest surfacing priority.
7.7:1 on term · 7.5:1 on bg · AAA
waiting · permperm
Blocked on a permission dialog vs. asking a question. Same hue, ringed square + "perm" tag — distinguished by shape, not a second color. (Phase 7)
shares waiting contrast · shape-split
blocked#e070c8
A parent whose blocking child is unfinished. Magenta diamond. The diamond ≠ the square (waiting) and the magenta ≠ the amber blocking-edge line, so the two amber-adjacent ideas never collide. (Phase 6)
6.8:1 on term · 6.6:1 on bg · AAA
idle#6b7280
Done or stale — should recede. Filled circle, no motion. Same silhouette as working, but stillness + lower lightness read instantly as "nothing happening here."
4.0:1 · non-text indicator ✓ (name uses --cc-meta)
unknown#a78bfa
Parser degraded, state undetermined. Hollow circle — the empty center says "we're not sure," graceful rather than alarming.
7.2:1 on term · 7.0:1 on bg · AAA

08

Motion

Restrained and meaningful. Only three things move, and only the working pulse runs continuously. Nothing blinks for its own sake; everything is GPU-cheap (transform + opacity + box-shadow), because dozens of pulses may run at once.

Working pulse
2400ms box-shadow ripple, ease-out, infinite. The signature life-sign. Calm at any count.
Attention arrival
One-shot ring when a session enters waiting. Fires once, then rests — never a persistent blink.
Category swap
260ms crisp cross-fade of tree + terminal. No slide, no bounce — glanced at constantly.
REDUCED MOTION prefers-reduced-motion → the working pulse becomes a static 1px ring, arrival becomes a 1-frame fill, transitions drop to 0ms. Status never depends on the motion, so nothing is lost.
