**New:**
- On ⌘Q or the menu's Quit, the app asks whether to close the sessions it started: Yes, No, or Select which to preserve…. Sessions working or waiting on you keep running unless you pick them. Esc cancels quitting. "Remember my choice" sets Settings › General › "When the app quits". The Dock's Quit, logging out and shutting down close nothing.
- Check for Updates… in the app menu.
- The 5h and 7d meters read Claude Code's own /usage every few minutes, falling back to the sessions' readings.
- Spend has a third source, Credits: usage credits spent this billing period, from /usage.
- The ? panel lists limits beside 5h and 7d, such as a model's own weekly limit, with their pace. The ? button takes the color of the worst one.

**Changed:**
- The app shows as "CC Command Center" in Finder, the Dock, the menus and About. Its data folder, its Keychain item and its updates are unchanged, so your settings, sessions and saved keys carry over.

**Fixed:**
- When Claude Code restarts a session on its own, the app checks it the same way it checks the restarts it starts, and stops the session if the check fails.
- The app's replies to its sessions are signed with a key only the app holds, so a process that reads a session's settings can't answer in the app's place.
- The PATH alert no longer lists sessions that have your PATH. Each session now reports the PATH its tools run with; sessions started before the update are listed as "may be missing your PATH", with Resume.
- Sessions started before the update keep the older reply check after a resume, because a resume keeps them on the version they started with. A band names them, with Start a copy for each.
- A /clear in a session no longer leaves it ended and lost from the sidebar. The app follows it to its new id, with its name, category, channel and spend.
- A new session waiting on a question in the session, such as approving a project's MCP server, shows "NEEDS YOU · IN SESSION" with Claude Code's words, and opening it takes you to the question. Before, it read as ended, and opening it started a second session beside it.
- A session that had a /clear and then stopped can be prompted, resumed and copied. Before, the app lost track of it once it stopped, and a copy started from the conversation before the /clear.
- A session the app had just opened in Focus is checked like any other when Claude Code restarts it by itself. So is a restart during which Claude Code briefly lists the session under another id; that no longer counts as a /clear.
- A session waiting on you notifies once, and again only for a new request. Before, one permission prompt could notify every few seconds.
- A session whose model, effort or name you changed in the session, or that watches an artifact, resumes. Before, the app refused it as changed after launch.
- A session whose permission mode you raised in the session, or that added a folder outside its own with /add-dir, shows what changed, such as 'Saved settings: auto, + "/opt/shared". Launched as default.', with Resume with these settings. Confirming records them, so later restarts on them go ahead. A permission mode that skips approvals is refused unless the app launched the session with it, and so are your home folder, Claude Code's folder and the app's own folders.
- Every new process of a session the app launched is checked against what the app launched it with, whether the app or Claude Code started it, including restarts while the app is closed, which it checks when it next starts. A process that fails the check is stopped, and stays refused until you resume the session from the app.
- When you first start this beta, running sessions whose saved settings go beyond their launch, such as a mode you raised with Shift+Tab, are stopped. Open each one and click Resume with these settings once; later restarts on those settings go ahead.
- A reply key the app can't read, as when the Keychain is locked, or whose file was removed, is no longer replaced. The alerts list the session's channel until you resume the session from the app, or, for a locked Keychain, until the key reads again.
- A session the app launched in an earlier build, with no record of which reporter mod copy it uses, opens. Before, only Resume found and checked its copy, and opening it was refused with "the app has no record of which reporter mod copy this session uses".
