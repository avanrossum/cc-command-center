The first release of the new CC Command Center, the successor to 0.24, rebuilt on Claude Code's own background sessions.

**Requirements:** macOS on Apple Silicon, and Claude Code 2.1.311 or later, installed and signed in.

**What it does:**
- Shows every Claude Code background session as a card, grouped by category, with what it's doing and whether it needs you.
- Answers permission prompts from the card, sends prompts, and opens a session's terminal in the app.
- Launches, resumes and stops sessions. Sessions keep running when the app quits.
- Imports 0.24's settings, categories and session names, and moves 0.24's running and parked sessions in, keeping their conversations. 0.24's own data is only read.

**From 0.24:** 0.24 doesn't update to this app. Install it from the disk image below, next to 0.24 or in its place. There is no dictation in this app.
