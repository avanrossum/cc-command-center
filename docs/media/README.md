# Media assets for the README

Drop screenshots and screen recordings here, named to match the placeholders in
the top-level `README.md`. Each placeholder in the README is a visible blockquote
describing the shot to capture; replace it with the matching image or a GIF/MP4.

**Before capturing anything:** use a clean demo state. The app shows your real
category names, session names, and working directories — capture with neutral
demo categories and throwaway sessions, never real client work.

Suggested formats: PNG for stills, MP4 or GIF for motion. Keep GIFs under ~10 MB
so the README stays fast to load.
